## 💰 Python Expense Tracker

A simple command-line Expense Tracker built using Python as part of the **DecodeLabs Python Programming Internship (Week 1 - Project 2)**.

- 📊 Calculate Total Expenses
- 🔁 Continuous Input

## 🛠️ Tech Stack

- VS Code
- Git & GitHub

## ▶️ Run
